| 术语 | 含义 |

4. 出厂未固化 eMMC 系统，建议手动固化

### 二、使用概要
#### 2.1 接口测试结果汇总
| 接口 | 功能 | 测试结果 | 关键性能 |
|---|---|---|---|
| LED/KEY/RTC | 控制/检测/时钟 | ✅ | - |
| DDR | 读写 | ✅ | 读 7623MB/s / 写 2208MB/s |
| Micro SD | 读写 | ✅ | 写 20.9MB/s / 读 23.7MB/s |
| eMMC | 读写 | ✅ | 写 31MB/s / 读 231MB/s |
| USB2.0 HOST | 读写 | ✅ | 写 31.9MB/s / 读 35.5MB/s |
| USB2.0 OTG(Host) | 读写 | ✅ | 写 35.9MB/s / 读 37.8MB/s |
| NVMe | 读写 | ✅ | 写 364MB/s / 读 378MB/s |
| RS232/RS485 | 收发 | ✅ | - |
| CAN | 收发 | ✅ | - |
| HDMI | 显示 | ✅ | 1080p60 |
| LVDS/MIPI LCD | 显示/背光/触摸 | ✅ | - |
| Audio | 录音/播放 | ✅ | - |
| ETH0(RGMII) | 千兆网 | ✅ | TCP 941Mbps / UDP 956Mbps |
| ETH1/2/3 | 百兆网 | ✅ | TCP ~94Mbps / UDP ~95.6Mbps |
| FAN/ADC/JTAG/PLP | 功能 | ✅ | - |

#### 2.2 常用设备节点
- LED：`/sys/class/leds/user-ledX`
- KEY：`/dev/input/eventX`
- RTC：`/dev/rtcX`
- eMMC：`/dev/mmcblk0`
- SD：`/dev/mmcblk1`
- 串口：`/dev/ttySX`
- CAN：`/sys/class/net/canX`
- 网口：`eth0/eth1/eth2/eth3`
- 显示：`/dev/fbX`
- 音频：`/dev/snd/`
- ADC：`/sys/bus/iio/devices/iio:deviceX`

#### 2.3 分区说明
- SD 卡：`mmcblk1p1~p9`（uboot/misc/boot/recovery/backup/rootfs/oem/amp/userdata）
- eMMC：`mmcblk0p1~p9`（结构同上）

##  三、评估板快速测试
#### 3.1 系统启动
1. 插入 SD 启动卡 → 接 HDMI → 接 USB 转 UART0
2. 串口工具：115200 8N1
3. 上电自动从 SD 启动，自动登录 root
4. LED 状态：LED0 电源常亮 → LED2 U‑Boot 亮 → 内核心跳闪烁

#### 3.2 文件传输
##### SD 卡方式
1. Ubuntu 挂载 SD 卡分区 `/dev/sdb6`
2. 拷贝文件 → 卸载 → 插回评估板

##### OpenSSH 方式
```bash
# 评估板获取IP
udhcpc -i eth0
ifconfig

# 从PC传文件到评估板
scp test1 root@192.168.13.43:/

# 从评估板传文件到PC
scp root@192.168.13.43:/test2 ./

# SSH登录
ssh root@192.168.13.43
# 密码：rockchip
```

#### 3.3 LED 控制
```bash
echo 1 > /sys/class/leds/user-led0/brightness  # LED1 亮
echo 0 > /sys/class/leds/user-led0/brightness  # LED1 灭
echo 1 > /sys/class/leds/user-led1/brightness  # LED2 亮
echo 0 > /sys/class/leds/user-led1/brightness  # LED2 灭
```

#### 3.4 按键功能
- KEY1：复位
- KEY2：短按休眠/唤醒；长按 6s 关机
- KEY3/4/5：用户按键
```bash
# 测试按键
cat /proc/bus/input/devices
od -x /dev/input/eventX
```

#### 3.5 外部 RTC
```bash
# 查看设备
ls /dev/rtc*
# 设置时间
date -s "2024-02-22 08:30:00"
# 同步到硬件时钟
hwclock --systohc -u -f /dev/rtc0
# 从硬件时钟同步
hwclock --hctosys -u -f /dev/rtc0
```

#### 3.6 DDR 性能
```bash
bw_mem -P 4 -N 10 64M frd   # 读
bw_mem -P 4 -N 10 64M fwr   # 写
bw_mem -P 4 -N 10 64M fcp   # 拷贝
stream -M 64M -P 4 -N 10    # Stream
```

#### 3.7 SD / eMMC / USB / NVMe 测速
统一使用 fio 测试：
```bash
# 写
fio -filename=/dev/设备节点 -direct=1 -rw=write -bs=1M -size=1G

# 读
fio -filename=/dev/设备节点 -direct=1 -rw=read -bs=1M -size=1G
```
- SD：`/dev/mmcblk1`
- eMMC：`/dev/mmcblk0`
- USB 硬盘：`/dev/sda`
- NVMe：`/dev/nvme0n1`

#### 3.8 USB OTG Device 模式
```bash
echo usb_ums_en > /etc/init.d/.usb_config
echo "ums_block=/tmp/ums_fat.img" >> /etc/init.d/.usb_config
echo "ums_block_size=32" >> /etc/init.d/.usb_config
echo "ums_block_type=fat" >> /etc/init.d/.usb_config
sync
usbdevice restart
```
PC 会识别为 U 盘，可用 ATTO DiskBenchmark 测试。

#### 3.9 串口测试（RS232 / RS485）
```bash
stty -F /dev/ttyS2 115200
echo test > /dev/ttyS2   # 发送
cat /dev/ttyS2          # 接收
```
- RS232：`ttyS2`
- RS485：`ttyS3` / `ttyS4`

#### 3.10 CAN 测试
```bash
ip link set can0 down
ip link set can0 type can bitrate 1000000
ip link set can0 up

# 发送
cansend can0 000#00.01.02.03.04.05.06.07

# 接收
candump can0
```

#### 3.11 显示输出
##### HDMI
默认 1920×1080@60fps，支持 720p/480p，需替换 uboot + kernel。

##### LVDS / MIPI LCD
1. 烧录专用内核：`boot-lvds-lcd.img` / `boot-mipi-lcd.img`
```bash
dd if=boot-xxx.img of=/dev/mmcblk1p3 conv=fsync
reboot
```
2. 背光调节
```bash
echo 128 > /sys/class/backlight/backlight/brightness
echo 255 > /sys/class/backlight/backlight/brightness
```
3. 触摸校准
```bash
weston-calibrator
```

#### 3.12 音频测试
```bash
# 录音 10s
arecord -c 1 -f S16_LE -r 44100 -d 10 test.wav

# 播放
aplay test.wav
```

#### 3.13 外部看门狗
```bash
echo 495 > /sys/class/gpio/export
echo out > /sys/class/gpio/gpio495/direction

# 喂狗
while true
do
    echo 1 > /sys/class/gpio/gpio495/value
    sleep 1
    echo 0 > /sys/class/gpio/gpio495/value
    sleep 1
done
```

#### 3.14 ADC 电压采集
```bash
cat /sys/bus/iio/devices/iio:device0/in_voltage2_raw
```
计算公式：`Vin = D × 1.8V / 1023`

#### 3.15 网络测试
```bash
# 获取IP
udhcpc -i eth0

# 连通性
ping www.baidu.com -I eth0

# 带宽（PC运行 iperf3 -s）
iperf3 -c PC_IP          # TCP
iperf3 -u -c PC_IP -b 1000M  # UDP
```

#### 3.16 风扇控制
```bash
echo 0 > /sys/class/pwm/pwmchip1/export
echo 40000 > /sys/class/pwm/pwmchip1/pwm0/period
echo 20000 > /sys/class/pwm/pwmchip1/pwm0/duty_cycle
echo 1 > /sys/class/pwm/pwmchip1/pwm0/enable  # 开
echo 0 > /sys/class/pwm/pwmchip1/pwm0/enable  # 关
```

#### 3.17 JTAG 调试
1. 替换 J-Link 驱动为 WinUSB
2. 评估板进入 Maskrom 模式
3. 运行 OpenOCD
4. Telnet 连接 localhost:4444 访问 CPU

#### 3.18 PLP 掉电保护
```bash
chmod +x plp.sh
./plp.sh 10 &
```
断电后模块继续供电 10s。

## 四、静态 IP 设置
```bash
vi /etc/dhcpcd.conf

# 添加示例
interface eth0
static ip_address=192.168.13.222/24
static routers=192.168.13.254
static domain_name_servers=202.96.128.86
```
保存重启后生效。

## 五、显示界面旋转
```bash
# 临时旋转
echo "output:DSI-1:rotate90" > /tmp/.weston_drm.conf

# 永久旋转
vi /etc/xdg/weston/weston.ini
# 添加
[output]
name=DSI-1
transform=rotate-90

# 重启桌面
/etc/init.d/S49weston restart
```
支持：rotate-90 / rotate-180 / rotate-270

## 五、PCIe 网卡扩展测试
支持模块：
- IO‑PCE6801‑GLAN（单口千兆）
- N500L‑AM2C‑DD（双口千兆）
- N500L‑AM4C‑QD（四口千兆）

### 5.1 驱动加载
```bash
insmod yt6801.ko      # 单口模块
insmod rnpgbe.ko      # 双口/四口模块
```

### 5.2 配置静态 IP
```bash
vi /etc/dhcpcd.conf
# 配置 enp1s0f0 / enp1s0f1 / enp1s0f2 / enp1s0f3
```

### 5.3 带宽测试
```bash
# 双口/四口并行TCP
iperf3 -c 192.168.77.11 > log1 &
iperf3 -c 192.168.78.11 > log2 &
```
