本章节主要描述开发板相关源码的编译方法，包括全编译方法、单独编译内核方法。

## 5.1编译前准备
### 5.1.1 📚<font style="color:#000000;">环境说明</font>
+ 开发环境操作系统：Ubuntu20.04  64位版 或 Ubuntu22.04  64位版
+ 交叉工具链：aarch64-linux-gnu
+ 开发板使用Bootloader 版本：u-boot-2018.07
+ 开发板内核版本：linux-5.10.208
+ 开发板系统版本：OpenHarmony-5.0 release

### 5.1.2 拷贝源码
🛤️程序源码：用户资料\1-镜像及源码\1-源码\forlinx-5.0-release.bz2.*（00到17）

创建工作目录

```bash
forlinx@ubuntu:~$ mkdir -p /home/forlinx/t527						//按照顺序创建工作目录
```

将用户资料中的源码文件forlinx-5.0-release.tar.bz2.*拷贝到虚拟机/home/forlinx/t527目录。

```bash
forlinx@ubuntu:~$ cd /home/forlinx/t527									//切换到工作目录
forlinx@ubuntu:~/t527$ cat forlinx-5.0-release.tar.bz2.* > forlinx-5.0-release.tar.bz2
forlinx@ubuntu:~/t527$ tar -xvf forlinx-5.0-release.tar.bz2			//在当然位置解压压缩包
```

运行命令后等待完成即可。



本源码对编译环境的硬件配置要求较高：在高配置环境（如服务器）下编译可显著缩短编译时间；若直接在默认提供的开发环境（虚拟机）中编译，易出现系统卡死的问题。  

若需在默认提供的开发环境（虚拟机）中完成编译，可通过以下修改适配源码，此操作会增加整体的编译时间：  



## 5.2 源码编译
⁉️**注意：**

+ **初次解压内核源码后，需要先对源码进行整体编译**
+ **整体编译过后，可根据实际情况再进行单独编译**
+ **该源码编译需要开发环境运行内存16G及以上，请不要修改我们提供的VM虚拟机镜像配置**
+ **手册中第二章节使用的是3588虚拟机，需要按照3.1.7章节的“OKt527 Openharmony开发环境搭建方法手动配置openharmony开发环境**

### <font style="color:#000000;">5.2.1 编译测试</font>
在源码路径内，提供了编译脚本build.sh，运行该脚本对整个源码进行编译，需要在终端切换到解压出来的源码路径，找到build.sh文件。

```bash
forlinx@ubuntu:~$ cd /home/forlinx/t527/forlinx-5.0-release
```

以下操作需要在源码目录下操作，全编译方法：

```bash
forlinx@ubuntu:~/t527/forlinx-5.0-release$ cd device/board/forlinx/okt527/patch
forlinx@ubuntu:~/t527/forlinx-5.0-release/device/board/forlinx/okt527/patch$ ./pre_build.sh
forlinx@ubuntu:~/t527/forlinx-5.0-release/device/board/forlinx/okt527/patch$ cd -
forlinx@ubuntu:~/t527/forlinx-5.0-release$ bash build/prebuilts_download.sh

//全编译；如果进行了修改，编译后发现修改不生效，需要先删掉out目录再编译
forlinx@ubuntu:~/t527/forlinx-5.0-release$ ./build.sh --product-name okt527 --ccache
//单独编译内核，如果对内核进行了修改，需要先删掉out/KERNEL_OBJ，再运行单独编译内核命令
forlinx@ubuntu:~/t527/forlinx-5.0-release$ ./build.sh --product-name okt527 --ccache --build-target kernel --gn-args linux_kernel_version=\"linux-5.10\"
```

或者采用OpenHarmony-v5.0.0-release 基线进行开发：

```bash
forlinx@ubuntu:~$ mkdir forlinx-5.0-release
forlinx@ubuntu:~$ cd forlinx-5.0-release
forlinx@ubuntu:~/forlinx-5.0-release$ repo init -u https://gitee.com/openharmony/manifest -b refs/tags/OpenHarmony-v5.0.0-Release --no-repo-verify
#采用这种方式，需要先注册gitee.com账号，并将gitee.com账号的用户名密码信息配置到SSH密钥中，否则会报错提示“Permission denied”，即没有权限
forlinx@ubuntu:~/forlinx-5.0-release$ repo sync -c
forlinx@ubuntu:~/forlinx-5.0-release$ repo forall -c 'git lfs pull'
```

将用户资料中device_board_forlinx.tar.bz2和vendor_forlinx.tar.bz2解压：

forlinx@ubuntu:~/forlinx-5.0-release$ ./build.sh --product-name okt527 --ccache
