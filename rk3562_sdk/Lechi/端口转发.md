# 端口转发长期稳定方案

> 适用场景：RK3562 嵌入式设备端口转发，尤其是 SSH 等生产/重要服务转发  
> **不推荐 ncat（不够稳、容易断）**

---

## 一、长期使用推荐（从最稳到简单）

### 1）生产级、性能最好、最稳：iptables（内核级）

优点：内核转发、**几乎无性能损耗**、并发高、最稳定、系统自带、开机自启容易做。  
缺点：配置稍多，需要开启 ip_forward。

#### 快速配置（转发 8080 → 172.31.0.1:22）

```bash
# 1. 开启内核转发（永久）
echo 'net.ipv4.ip_forward=1' >> /etc/sysctl.conf
sysctl -p

# 2. 配置 NAT 转发
iptables -t nat -A PREROUTING -p tcp --dport 8080 -j DNAT --to-destination 172.31.0.1:22
iptables -t nat -A POSTROUTING -p tcp -d 172.31.0.1 --dport 22 -j SNAT --to-source 172.31.0.X  # 本机网卡IP

# 3. 保存规则（Ubuntu）
apt install iptables-persistent -y
netfilter-persistent save
```

- 重启不丢、不用进程守护、**长期首选**。

---

### 2）稳定、简单、通用：socat（用户态最佳）

优点：比 ncat 稳、支持 fork（多连接）、TCP/UDP 都能转、社区成熟、易做 systemd 自启。

#### 安装与长期命令

```bash
apt install socat -y

# 前台测试
socat TCP4-LISTEN:8080,reuseaddr,fork TCP4:172.31.0.1:22

# 后台长期运行
nohup socat TCP4-LISTEN:8080,reuseaddr,fork TCP4:172.31.0.1:22 > /dev/null 2>&1 &
```

- `fork`：支持多个 SSH 同时连，**ncat 做不到**。
- 适合：不想用 iptables、又要稳定长期转发。

#### socat systemd 服务（推荐）

```ini
# /etc/systemd/system/port-forward.service
[Unit]
Description=Port Forward 8080 -> 172.31.0.1:22
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/socat TCP4-LISTEN:8080,reuseaddr,fork TCP4:172.31.0.1:22
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now port-forward.service
systemctl status port-forward.service
```

---

### 3）加密+转发二合一：SSH 隧道（安全优先）

需要**加密**、且目标能 SSH 登录，长期用这个最安全。

```bash
# 本地端口转发：本机8080 → 172.31.0.1:22
ssh -N -L 0.0.0.0:8080:127.0.0.1:22 root@172.31.0.1

# 后台长期（加 autossh 防断连）
apt install autossh -y
autossh -M 0 -N -L 0.0.0.0:8080:127.0.0.1:22 root@172.31.0.1
```

- 优点：加密、认证、自动重连
- 缺点：有加密开销

#### autossh systemd 服务

```ini
# /etc/systemd/system/autossh-tunnel.service
[Unit]
Description=AutoSSH Tunnel 8080 -> 172.31.0.1:22
After=network.target

[Service]
Type=simple
Environment="AUTOSSH_GATETIME=0"
ExecStart=/usr/bin/autossh -M 0 -N -L 0.0.0.0:8080:127.0.0.1:22 root@172.31.0.1
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

---

### 4）不推荐长期：ncat / nc

- ncat：容易断、单连接、**不适合长期**，只适合临时调试。
- Ubuntu 对 ncat 支持一般。

---

## 二、长期使用对比

| 工具 | 稳定性 | 性能 | 多连接 | 长期推荐 |
|---|---|---|---|---|
| **iptables** | ⭐⭐⭐⭐⭐ | 内核级（最好） | ✅ | ✅ 生产首选 |
| **socat** | ⭐⭐⭐⭐ | 用户态（好） | ✅ | ✅ 简单稳定 |
| **autossh** | ⭐⭐⭐⭐ | 加密（一般） | ✅ | ✅ 安全优先 |
| **ncat** | ⭐⭐ | 用户态（一般） | ❌ | ❌ 临时用 |

---

## 三、最终建议

- 追求**最稳、最快、长期不维护**：用 **iptables**
- 想要**简单、不用记 iptables 规则**：用 **socat + systemd**
- 要**加密安全**：用 **autossh**
