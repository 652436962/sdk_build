# OK3562 Ubuntu + QCA9880（ath10k）改动明细与命令

> 记录本次（2026-10-20）在 `ok3562-sdk` 容器内实际执行的步骤，可照此复现。
> 容器：`ok3562-sdk`，SDK：`/workspace/OK3562-linux-source`。

---

## 1. 内核配置

```bash
cd /workspace/OK3562-linux-source

# 在 defconfig 追加 ath10k（幂等，已有则跳过）
D=kernel-5.10/arch/arm64/configs/OK3562_Linux_defconfig
grep -q '^CONFIG_ATH10K=' $D || printf '\nCONFIG_ATH10K=m\nCONFIG_ATH10K_PCI=m\n' >> $D

# 确认
grep -nE 'ATH10K|WLAN_VENDOR_ATH|CONFIG_WLAN=' $D
```

编译 Kernel：
```bash
./build.sh kernel
```
- 生成：`ath.ko`、`ath10k_core.ko`、`ath10k_pci.ko`
- `.config` 中应为：`CONFIG_ATH10K=m`、`CONFIG_ATH10K_PCI=m`、`CONFIG_ATH10K_CE=y`

---

## 2. 固件（QCA988X hw2.0）

主机解压（若为 `.zst`）：
```bash
mkdir -p /tmp/athfw && cd /tmp/athfw
zstd -d /lib/firmware/ath10k/QCA988X/hw2.0/firmware-5.bin.zst -o firmware-5.bin
zstd -d /lib/firmware/ath10k/QCA988X/hw2.0/board.bin.zst    -o board.bin
```

拷进容器并写入 rootfs：
```bash
docker cp /tmp/athfw/. ok3562-sdk:/tmp/athfw/

docker exec ok3562-sdk bash -lc '
  R=/workspace/OK3562-linux-source/ubuntu/jammy-rootfs.img
  mkdir -p /mnt/rfs && mount -o loop $R /mnt/rfs
  mkdir -p /mnt/rfs/lib/firmware/ath10k/QCA988X/hw2.0
  cp -v /tmp/athfw/* /mnt/rfs/lib/firmware/ath10k/QCA988X/hw2.0/
  sync && umount /mnt/rfs'
```

## 3. 内核模块安装 + depmod

```bash
docker exec ok3562-sdk bash -lc '
  K=/workspace/OK3562-linux-source/kernel-5.10
  R=/workspace/OK3562-linux-source/ubuntu/jammy-rootfs.img
  mkdir -p /mnt/rfs && mount -o loop $R /mnt/rfs
  M=/mnt/rfs/lib/modules/5.10.198/kernel/drivers/net/wireless/ath
  mkdir -p $M/ath10k
  cp -v $K/drivers/net/wireless/ath/ath.ko $M/
  cp -v $K/drivers/net/wireless/ath/ath10k/ath10k_core.ko \
        $K/drivers/net/wireless/ath/ath10k/ath10k_pci.ko $M/ath10k/
  depmod -b /mnt/rfs 5.10.198
  sync && umount /mnt/rfs'
```
检查 `modules.dep`：
```
kernel/drivers/net/wireless/ath/ath10k/ath10k_core.ko: .../ath.ko
kernel/drivers/net/wireless/ath/ath10k/ath10k_pci.ko:  .../ath10k_core.ko .../ath.ko
```

## 4. 分区表（解决 partition larger than flash）

```bash
docker exec ok3562-sdk bash -lc '
  P=/workspace/OK3562-linux-source/device/forlinx/.chips/ok3562/parameter-ubuntu-fit.txt
  cp -a $P $P.bak-12g
  NEW="CMDLINE: mtdparts=:0x00002000@0x00004000(uboot),0x00002000@0x00006000(misc),0x00020000@0x00008000(boot),0x00040000@0x00028000(recovery),0x00010000@0x00068000(backup),0x00B10000@0x00078000(rootfs),0x00040000@0x00B88000(oem),0x00002000@0x00BC8000(amp),-@0x00BCA000(userdata:grow)"
  sed -i "s|^CMDLINE:.*|$NEW|" $P
  cat $P'
```
- rootfs 5.53GiB（原 12.7G），总最小占用 ≈5.89GiB，8GB/16GB eMMC 均可。

## 5. 打包

```bash
docker exec -u 1000 ok3562-sdk bash -lc 'cd /workspace/OK3562-linux-source && ./build.sh updateimg'
```

产物：`output/update/Image/update.img`（≈5.8GB），`rockdev/update.img` 软链。

## 7. 注意事项

- **必须以 SDK 属主 UID（如 1000/builduser）执行 `./build.sh`**，root 会报内核模块安装 `Permission denied`。
- 本 SDK 实际内核目录是 **`kernel-5.10/`**（`kernel/` 不是实际构建目标）。
- 单独 `./build.sh kernel` 不会更新 `update.img`，需再 `./build.sh updateimg`。
- 如需开机自动加载，`ath10k_pci` 有 PCI alias，udev 会按 `modules.dep` 自动 `modprobe`；
  也可显式写 `/etc/modules-load.d/ath10k.conf`：`ath10k_pci`。
