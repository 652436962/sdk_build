# AP6275S 改动明细

> SDK：`rk3562_sdk/ubuntu`（RK3562 / TL3562-EVM，内核 5.10.209-rt89）

## 1. 驱动替换（`rkwifi/bcmdhd`）

| 项 | 旧 | 新 |
|----|----|----|
| 版本 | `101.10.361.18 (r892223-20220519-1)` | `101.10.361.36 (r892223-20231107-1)` |
| 路径 | `Kernel/drivers/net/wireless/rockchip_wlan/rkwifi/bcmdhd` | 同上（整体替换） |
| 备份 | — | `rkwifi/bcmdhd.orig` |

新增/变更文件（相对旧版）包含：`dhd_linux_rx.c`、`dhd_linux_tx.c`、`dhd_log_dump.c`、`fwpkg_utils.c`、`linuxerrmap.c`、`wl_timer.c` 等。

AP6275S 映射（`dhd_config.c`）：
```c
{BCM43752_CHIP_ID, 2, DONT_CARE, "bcm43752a2_ag", "ap6275s"},
```

## 2. 内核配置（`.config`，无需改，已具备）

```
CONFIG_BCMDHD=y
CONFIG_AP6XXX=m
CONFIG_BCMDHD_SDIO=y
# CONFIG_BCMDHD_PCIE is not set
CONFIG_BCMDHD_FW_PATH="/vendor/etc/firmware/fw_bcmdhd.bin"
CONFIG_BCMDHD_NVRAM_PATH="/vendor/etc/firmware/nvram.txt"
```
> 中断方式默认 OOB（`BCMDHD_OOB`），对应 dts 的 `WIFI,host_wake_irq`。

## 3. 设备树 `tl3562-evm-sdio-wifi.dts`

改动（相对 RTL8723DS 版）：
- 新增 `mmc-pwrseq = <&sdio_pwrseq>;`（RTL 版无 pwrseq）
- `&sdio_pwrseq` 由 `disabled` → `okay`，加 `post-power-on-delay-ms=<100>`
- `wifi_chip_type` 由 `rtl8723ds` → **`ap6275s`**
- `max-frequency` 1MHz → 50MHz

原文件已备份为 `tl3562-evm-sdio-wifi.dts.rtl8723ds.bak`。

## 4. 固件

| 文件 | 用途 | 必需 |
|------|------|------|
| `fw_bcm43752a2_ag.bin` | WiFi 固件 | ✅ |
| `nvram_ap6275s.txt` | NVRAM 校准 | ✅ |
| `clm_bcm43752a2_ag.blob` | CLM 法规 | ✅ |
| `fw_bcm43752a2_ag_apsta.bin` | AP/STA 并发 | 可选 |
| `fw_bcm43752a2_ag_mfg.bin` | 产测 | 可选 |

来源：`ok3562_sdk/.../external/rkwifibt/firmware/broadcom/AP6275S/wifi/`。
放置：rootfs `/vendor/etc/firmware/`。

## 5. 编译

```bash
cd rk3562_sdk/ubuntu
./build.sh kernel        # 输出 boot.img（含新 dtb + bcmdhd.ko）
# 固件放入 rootfs 后：./build.sh all 打包
```

## 7. 构建结果（2026-10-14）

| 项 | 结果 |
|----|------|
| 内核配置 | `CONFIG_AP6XXX=y`（bcmdhd **内建**，免装 .ko）；`CONFIG_BCMDHD=y` |
| `bcmdhd` | 内建（`built-in.a` 存在，`vmlinux/Image` 含 bcmdhd 符号），版本 `101.10.361.36` |
| dtb | `tl3562-evm-sdio-wifi.dtb` 含 `ap6275s` + `TL3562-EVM-SDIO-WIFI-AP6275S` |
| `boot.img` | ~42 MB（含新内核 + dtb） |
| 固件注入 | 直接挂载 `rootfs.img` → 写入 `/vendor/etc/firmware/` → 卸载 |
| `update.img` | `rk3562_sdk/ubuntu/rockchip/output/update/Image/update.img`（5.9 GB） |

> 打包坑：`build.sh updateimg` **不会**自动应用 `overlays/rootfs/`（`RK_ROOTFS_OVERLAY` 未在其内部导出、
> `post-overlay.sh` 需 `POST_ROOTFS`）；故本次改为挂载 `rootfs.img` 直接注入固件。
> 正式流程需在 `build.sh` 里补 `export RK_ROOTFS_OVERLAY=1` 并确保走 rootfs post 阶段。

## 8. 烧录

用 Rockchip 刷机工具（RKDevTool/upgrade_tool）加载 `update.img` 整体烧录，或按分区刷 `boot.img`+`rootfs.img`。
