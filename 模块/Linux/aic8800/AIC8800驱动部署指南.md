# AIC8800 WiFi/蓝牙驱动编译与部署指南

## 一、驱动简介

AIC8800 是一款支持 WiFi 和蓝牙的无线芯片，提供 SDIO 接口版本：
- **SDIO 版本**：支持 WiFi + 蓝牙，功能完整

## 二、内核是否有 AIC8800 驱动

**内核中没有集成 AIC8800 驱动**，需要单独编译。

检查方法：
```bash
# 检查内核源码中是否有 aic8800 驱动
grep -r 'AIC8800\|aic8800' /workspace/RK35xx/kernel-6.1/ --include='*.c' --include='*.h'

# 检查内核配置
grep -i 'CONFIG_AIC8800' /workspace/RK35xx/kernel-6.1/.config
```

## 三、编译驱动

### 3.1 修改 Makefile

编辑 `external/rkwifibt/drivers/aic8800_sdio/Makefile`：

```makefile
ifeq ($(CONFIG_PLATFORM_ROCKCHIP), y)
ARCH = arm64
KDIR ?= /workspace/RK35xx/kernel-6.1
CROSS_COMPILE ?= /workspace/RK35xx/prebuilts/gcc/linux-x86/aarch64/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/aarch64-none-linux-gnu-
ccflags-y += -DCONFIG_PLATFORM_ROCKCHIP
endif
```

### 3.2 执行编译

```bash
cd external/rkwifibt/drivers/aic8800_sdio
make clean
make -j$(nproc)
```

### 3.3 编译结果

```
aic8800_bsp/aic8800_bsp.ko
aic8800_fdrv/aic8800_fdrv.ko
aic8800_btlpm/aic8800_btlpm.ko
```

## 四、设备树配置

### 4.1 确认硬件接口

AIC8800 SDIO 模块连接到 RK3566 的 SDIO 接口（sdmmc2）。

### 4.2 修改设备树

在 `kernel-6.1/arch/arm64/boot/dts/rockchip/rk3566-x36-lp4x-v10.dts` 中添加：

```dts
&sdmmc2 {
    max-frequency = <150000000>;
    no-sd;
    no-mmc;
    bus-width = <4>;
    disable-wp;
    cap-sd-highspeed;
    cap-sdio-irq;
    keep-power-in-suspend;
    non-removable;
    pinctrl-names = "default";
    pinctrl-0 = <&sdmmc2m0_bus4 &sdmmc2m0_cmd &sdmmc2m0_clk>;
    sdmmc-pwrseq = <&sdio_pwrseq>;
    status = "okay";
};
```

### 4.3 重新编译内核

```bash
cd kernel
make ARCH=arm64 CROSS_COMPILE=<toolchain-path> rk3566-x36-lp4x-v10.img -j$(nproc)
```

## 五、部署到目标设备

### 5.1 传输驱动模块

```bash
scp aic8800_bsp.ko aic8800_fdrv.ko aic8800_btlpm.ko user@192.168.x.x:/tmp/
```

### 5.2 加载驱动模块

```bash
sudo insmod /tmp/aic8800_bsp.ko
sudo insmod /tmp/aic8800_fdrv.ko
sudo insmod /tmp/aic8800_btlpm.ko
```

### 5.3 验证加载状态

```bash
lsmod | grep aic
```

## 六、WiFi 测试

### 6.1 查看网络接口

```bash
ip link show
# 应该看到 wlan0
```

### 6.2 连接 WiFi

```bash
# 方法1: 使用 nmcli
sudo nmcli dev wifi connect 'TP-LINK_lc' password 'lechi2024' ifname wlan0

# 方法2: 使用 iw
sudo iw wlan0 connect 'TP-LINK_lc' key d:0:lechi2024

# 方法3: 使用 wpa_supplicant
sudo wpa_supplicant -B -i wlan0 -c /tmp/wpa.conf

# 获取 IP
sudo dhclient wlan0
```

### 6.3 WiFi 测试命令

```bash
# 扫描 WiFi 网络
sudo iw wlan0 scan | grep SSID

# 检查接口状态
ip addr show wlan0
```

## 七、蓝牙测试

### 7.1 初始化蓝牙串口

蓝牙通过 UART 串口连接，需要先初始化：

```bash
sudo hciattach -s 1500000 /dev/ttyS1 any 1500000 flow nosleep
# 输出: Device setup complete
```

### 7.2 检查蓝牙设备

```bash
hciconfig
# 应该看到 hci0
```

### 7.3 启动蓝牙

```bash
sudo hciconfig hci0 up
```

### 7.4 扫描蓝牙设备

```bash
# 经典蓝牙扫描
sudo hcitool scan

# BLE 扫描
sudo btmgmt -i hci0 find
```

### 7.5 测试结果

```
hci0:  Type: Primary  Bus: UART
       BD Address: 44:37:0B:73:5A:0C
       UP RUNNING
```

## 八、常见问题

### 问题1：SDIO 接口未识别

**现象**：驱动加载失败，报 `No such device`

**原因**：设备树中未启用 SDIO 接口

**修复方法**：
1. 确认设备树中 sdmmc2 状态为 "okay"
2. 重新编译内核并刷写

### 问题2：WiFi 无法连接

**检查步骤**：
1. 确认驱动加载：`lsmod | grep aic`
2. 确认接口存在：`ip link show wlan0`
3. 查看内核日志：`dmesg | grep aic`

### 问题3：蓝牙无法使用

**检查步骤**：
1. 确认蓝牙驱动加载：`lsmod | grep aic8800_btlpm`
2. 确认蓝牙设备：`hciconfig`
3. 启动蓝牙：`sudo hciconfig hci0 up`
