# 板卡 4G 共享上网配置文档

## 拓扑

```
摄像头 (192.168.1.64)
  ↓ eth0
板卡 (192.168.1.1)
  ↓ usb0
4G 模块 (udhcpc 拨号)
  ↓
公网
```

## 1. 串口连接板卡

```bash
picocom -b 115200 /dev/ttyUSB0
```

## 2. 一次性配置命令

在板卡串口终端逐条执行：

```bash
# 4G 拨号
udhcpc -i usb0
sleep 3

# 配置 eth0 静态 IP（作为摄像头网关）
ifconfig eth0 192.168.1.1 netmask 255.255.255.0 up

# 开启内核 IP 转发
echo 1 > /proc/sys/net/ipv4/ip_forward

# NAT 转发 — 将 eth0 局域网流量通过 usb0 出口
iptables -t nat -A POSTROUTING -o usb0 -j MASQUERADE

# 允许转发规则
iptables -A FORWARD -i eth0 -o usb0 -j ACCEPT
iptables -A FORWARD -i usb0 -o eth0 -m state --state RELATED,ESTABLISHED -j ACCEPT
```

## 3. 摄像头侧配置

登录摄像头 Web 管理页面 `http://192.168.1.64`，网络设置：

| 参数 | 值 |
|------|-----|
| IP | 192.168.1.64 |
| 掩码 | 255.255.255.0 |
| 默认网关 | 192.168.1.1 |
| DNS | 8.8.8.8 |

## 4. 验证

在板卡串口执行：

```bash
# 能否 ping 通摄像头
ping -c 2 192.168.1.64

# 板卡能否上网
ping -c 2 8.8.8.8

# 查看转发流量
iptables -L FORWARD -n -v

# 查看 NAT 是否生效
iptables -t nat -L POSTROUTING -n -v
```

预期 `eth0→usb0` 和 `MASQUERADE` 计数器非零，表示摄像头流量正在经板卡外发。

## 5. 开机自启（systemd 持久化）

### 5.1 部署 4G 路由服务

将 `4g-route.service` 拷贝到板卡并启用：

```bash
cp 4g-route.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable 4g-route
systemctl start 4g-route
```

### 5.2 部署断线保活服务（可选）

将 `4g_keepalive.sh` 和 `4g-keepalive.service` 拷贝到板卡：

```bash
cp 4g_keepalive.sh /usr/local/bin/
chmod +x /usr/local/bin/4g_keepalive.sh
cp 4g-keepalive.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable 4g-keepalive
systemctl start 4g-keepalive
```

### 5.3 服务管理命令

```bash
# 查看服务状态
systemctl status 4g-route
systemctl status 4g-keepalive

# 查看日志
journalctl -u 4g-route -f
journalctl -u 4g-keepalive -f

# 重启服务
systemctl restart 4g-route
```

## 6. 常用排查

| 现象 | 检查 |
|------|------|
| 摄像头不能上网 | 摄像头网关是否指向 `192.168.1.1` |
| eth0 无 IP | `ifconfig eth0` 是否掉了，链路是否掉线 |
| usb0 无 IP | `ifconfig usb0`，重新 `udhcpc -i usb0` |
| 转发无流量 | `cat /proc/sys/net/ipv4/ip_forward` 是否为 1 |
| NAT 未生效 | `iptables -t nat -L -n` 检查规则 |
