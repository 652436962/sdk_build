# 海康推流测试

## 1. 端口转发

### 目的
将海康摄像头的 RTSP 流通过端口转发暴露到公网或内网其他网段，便于远程访问。

### 常见端口
| 端口 | 用途 |
|------|------|
| 554 | RTSP 默认端口 |
| 80 | HTTP 管理页面 | 
| 8000 | 海康 SDK 服务端口 |

### SSH 端口转发示例

```bash
# 本地转发：将远程摄像头的 554 端口映射到本地 1554
ssh -L 1554:192.168.1.64:554 user@跳板机 -N

# 然后通过本地端口访问
vlc rtsp://localhost:1554/Streaming/Channels/101
```

### socat 转发示例

```bash
# 在中间服务器上使用 socat 转发 RTSP
socat TCP-LISTEN:8554,fork,reuseaddr TCP:192.168.1.64:554
```

前台测试（多连接、稳定）
socat TCP4-LISTEN:8554,fork,reuseaddr TCP4:172.31.0.100:554
后台长期运行（生产用）
nohup socat TCP4-LISTEN:8554,fork,reuseaddr TCP4:172.31.0.100:554 > /dev/null 2>&1 &

## 2. VLC RTSP 视频流播放

### 拉取海康 RTSP 流

rtsp://admin:12345@192.168.10.31:8554/h264/ch1/main/av_stream

海康摄像头 RTSP URL 格式：
```
rtsp://[用户名]:[密码]@[IP]:[端口]/Streaming/Channels/[通道号][码流类型]01
```

- `101`：通道 1 主码流
- `102`：通道 1 子码流

### VLC 命令行拉流

```bash
# 直接播放
vlc rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101

# 拉流并转推为 HTTP 流（VLC GUI 方式）
vlc rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101 \
    --sout '#transcode{vcodec=h264,acodec=none}:http{mux=ts,dst=:8080/stream}'
```

### VLC RTSP 转 HTTP 流

```bash
# 以 http 方式转发，其他设备可通过 http://IP:8080/stream 访问
cvlc rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101 \
    --sout '#standard{access=http,mux=ts,dst=0.0.0.0:8080/stream}' \
    --intf dummy
```

### VLC RTSP 转 RTSP（重新发布）

```bash
cvlc rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101 \
    --sout '#rtp{sdp=rtsp://0.0.0.0:8554/restream}' \
    --intf dummy
```

## 3. RTMP 推流

### 使用 FFmpeg 将 RTSP 转推 RTMP

```bash
# 推流到 RTMP 服务器（如 Nginx-RTMP、SRS）
ffmpeg -rtsp_transport tcp \
    -i "rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101" \
    -c copy -f flv \
    rtmp://rtmp-server:1935/live/stream_key
```

### 常见 RTMP 服务器

| 服务器 | 默认端口 | 说明 |
|--------|----------|------|
| Nginx-RTMP | 1935 | 基于 Nginx 模块 |
| SRS | 1935/1985 | 高性能流媒体服务器 |
| MediaMTX | 8554/1935 | 支持多协议 |

### Docker 快速搭建 SRS

```bash
docker run -d --name srs \
    -p 1935:1935 -p 1985:1985 -p 8080:8080 \
    ossrs/srs:5 ./objs/srs -c conf/docker.conf
```

### 使用 VLC 转推 RTMP

```bash
cvlc rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101 \
    --sout '#transcode{vcodec=h264,acodec=none}:std{access=rtmp,mux=flv,dst=rtmp://rtmp-server:1935/live/stream_key}' \
    --intf dummy
```

### 拉取 RTMP 播放

```bash
# VLC 播放 RTMP
vlc rtmp://rtmp-server:1935/live/stream_key

# ffplay 播放
ffplay rtmp://rtmp-server:1935/live/stream_key
```

## 4. 萤石云设备播放

### 设备信息

| 参数 | 值 |
|------|-----|
| 设备序列号 | AY5549315 |
| 通道号 | 1 |

### 控制台播放页

```
https://open.ys7.com/console/device/detail.html?deviceSerial=AY5549315&channelNo=1&accessType=1&playType=1
```

### 播放地址格式

```bash
# HLS 流（需通过 API 获取 accessToken）
https://hls.ys7.com/openlive/<deviceSerial>_<channelNo>.m3u8

# RTMP 流
rtmp://rtmp.ys7.com/openlive/<deviceSerial>_<channelNo>

# FLV 流
https://flv.ys7.com/openlive/<deviceSerial>_<channelNo>.flv
```

> 以上播放地址需先在萤石开放平台创建应用、获取 accessToken，并调用直播地址获取接口 `/api/lapp/live/address/get` 获得带签名的完整 URL。

### API 获取播放地址

```bash
# 获取 accessToken
# POST https://open.ys7.com/api/lapp/token/get
# Body: appKey=<appKey>&appSecret=<appSecret>

# 获取直播地址
# POST https://open.ys7.com/api/lapp/live/address/get
# Body: accessToken=<token>&source=<deviceSerial>:<channelNo>
```

## 测试流程总结

1. **端口转发** → 确保能访问到摄像头网络
2. **VLC 拉 RTSP** → 验证原始流可用
3. **RTMP 推流** → 将 RTSP 转为 RTMP 推送到流媒体服务器
4. **拉流验证** → 通过 VLC/ffplay 播放 RTMP 确认推流成功
