# T527 OpenHarmony 5.0.3 适配移远 EC20 外挂 Modem 模组（非鸿蒙框架，仅实现上网）

---

## 一、适配 USB 驱动
EC20 模组支持 QMI、ECM、RNDIS、USB 转串口 option 等驱动，本文选择 **QMI 驱动** 适配。

### 1. USB 驱动配置项
| USB 驱动 | 配置项 | 源文件 |
| --- | --- | --- |
| ACM | CONFIG_USB_ACM | [KERNEL]/drivers/usb/class/cdc-acm.c |
| QMI | CONFIG_USB_SERIAL_WWAN=y<br>CONFIG_USB_SERIAL_QMI_WWAN=y | [KERNEL]/drivers/usb/serial/qmi_wwan.c |
| ECM | CONFIG_USB_NET_DRIVERS=y<br>CONFIG_USB_USBNET=y<br>CONFIG_USB_NET_CDCETHER=y | [KERNEL]/drivers/net/usb/cdc_ether.c |
| RNDIS | CONFIG_USB_NET_DRIVERS<br>CONFIG_USB_USBNET<br>CONFIG_USB_NET_RNDIS_HOST | [KERNEL]/drivers/net/usb/rndis_host.c |
| MBIM | CONFIG_USB_NET_DRIVERS<br>CONFIG_USB_USBNET<br>CONFIG_USB_NET_CDC_MBIM | [KERNEL]/drivers/net/usb/cdc_mbim.c |

### 2. 内核配置修改
在 `t527_standard_defconfig` 中添加：
```ini
CONFIG_USB_SERIAL_WWAN=y
CONFIG_USB_SERIAL_QMI_WWAN=y
```

## 三、移植 quectel-CM 拨号工具
### 1. 获取源码
向移远客服获取：`Quectel_QConnectManager_Linux_V1.6` 源码。

### 2. 核心源文件
```
QmiWwanCM.c
GobiNetCM.c
main.c
QCQMUX.c
QMIThread.c
util.c
qmap_bridge_mode.c
mbim-cm.c
device.c
atc.c
atchannel.c
at_tok.c
udhcpc.c
```

### 3. 编写 BUILD.gn
路径：`third_party/quectel/quectel-cm/BUILD.gn`
```gn
import("//build/ohos.gni")

group("quectel-cm-group") {
  deps = [
    ":quectel-CM"
  ]
}

ohos_executable("quectel-CM") {
  sources = [
    "QmiWwanCM.c",
    "GobiNetCM.c",
    "main.c",
    "QCQMUX.c",
    "QMIThread.c",
    "util.c",
    "qmap_bridge_mode.c",
    "mbim-cm.c",
    "device.c",
    "atc.c",
    "atchannel.c",
    "at_tok.c",
    "udhcpc.c"
  ]

  defines = [
    "USE_OHOS"
  ]

  include_dirs = [
    "//third_party/quectel/quectel-cm",
  ]

  install_enable = true
  part_name = "ril_adapter"
  subsystem_name = "telephony"
  install_images = [
    "system",
    "updater"
  ]

  cflags = [
    "-Wall",
    "-Wno-unused-function",
    "-Wno-unused-variable",
    "-Wno-missing-braces"
  ]
}
```

### 4. 加入编译依赖
修改 `base/telephony/ril_adapter/bundle.json`，添加：
```json
"//third_party/quectel/quectel-cm:quectel-cm-group"
```

### 5. 编译命令
```bash
./build.sh --product-name t527 --ccache
```
编译后产物路径：`out/t527/packages/phone/system/bin/quectel-CM`

## 四、自启动 quectel-CM 拨号工具
修改 `device/board/hihope/t527/cfg/init.t527.cfg`：

### 1. 添加服务配置
```json
{
  "name": "quectel-cm",
  "path": ["/system/bin/quectel-CM"],
  "secon": "u:r:su:s0",
  "uid": "root",
  "gid": ["root", "system"]
}
```

### 2. 添加启动时序
修改 `./base/startup/init/services/etc/init.cfg`：
```json
"jobs": [
  {
    "name": "post-fs-data",
    "cmds": [
      ...,
      "wait /dev/ttyUSB2",
      "start quectel-cm"
    ]
  }
]
```

> **注意**：实际测试中，通过 init.cfg 配置自启动可能不生效，建议手动启动或使用其他自启动方式。

### 3. secon 说明
- 格式：`u:r:domain:s0`
- 自定义 `quectel-cm` 域因无 SELinux 策略会启动失败，改用系统预定义的 `su` 域（`u:r:su:s0`）可正常启动。

## 五、遇到的问题及解决

### 问题一：缺少 busybox 工具
- **现象**：`busybox: inaccessible or not found`
- **解决**：将 busybox 预编译内置到系统。
  路径：`device/board/hihope/t527/modem/BUILD.gn`
```gn
ohos_prebuilt_executable("busybox") {
  source = "busybox/busybox"
  install_enable = true
  part_name = "rockchip_products"
}
```

### 问题二：缺少 default.script 文件
- **现象**：拨号失败，提示找不到 default.script
- **解决**：
  1. 从 QConnectManager 工具包获取并修改：`/sbin/route` → `busybox route`，`/sbin/ifconfig` → `ifconfig`
  2. 在 `build/ohos/images/mkimage/dac.txt` 添加权限：
```
system/etc/udhcpc/*,0777,0,2000,0
```

如果上述步骤不起作用，改用手动传输文件：
```bash
# 手动传输 default.script 文件
hdc target mount
hdc shell
cd /etc
mkdir -p udhcpc
exit
hdc file send default.script /etc/udhcpc/
hdc shell chmod 777 /etc/udhcpc/default.script
```

### 问题三：QMI 设备节点未创建
- **现象**：`QMI device not found`
- **解决**：
  1. 确认 USB 驱动加载成功：`ls /dev/cdc-wdm0`
  2. 检查 USB 枚举顺序，确保 EC20 正常识别

### 问题四：quectel-cm 与 /dev/ttyUSB2 时序问题
- **现象**：进程启动早于 USB 设备枚举，立即退出
- **解决**：启动前添加 `wait /dev/ttyUSB2`

### 问题五：DNS 解析问题
- **解决**：
  1. 修改 `build/config/components/musl/BUILD.gn`：
```ini
OHOS_DNS_PROXY_BY_NETSYS=0
OHOS_FWMARK_CLIENT_BY_NETSYS=0
```
  2. 修复 `third_party/musl/src/network/resolvconf.c`：
```c
// 原：#ifdef OHOS_FWMARK_CLIENT_BY_NETSYS
// 改：#if OHOS_FWMARK_CLIENT_BY_NETSYS
```

## 七、EC20 QMI 模式说明
quectel-CM 支持多种工作模式，使用 QMI 方式时：
- 设备节点：`/dev/cdc-wdm0`（QMI 控制通道）
- AT 命令口：`/dev/ttyUSB2`
- 网络接口：`usb0` 或 `wwan0`

### AT 命令切换模式
```bash
# 查询当前模式
AT+QCFG="usbnet"

# 切换到 QMI 模式
AT+QCFG="usbnet",1

# 切换到 ECM 模式
AT+QCFG="usbnet",0
```

## 八、手动启动 quectel-CM 拨号
如果自启动不生效，可手动启动拨号：

```bash
# 手动启动 quectel-CM
quectel-CM -d /dev/cdc-wdm0 &

# 或者指定 APN 启动
quectel-CM -d /dev/cdc-wdm0 -s internet &
```

---

**注意事项**：
1. EC20 模组需支持 QMI 固件版本
2. 不同地区运营商 APN 可能不同，需根据实际情况修改
3. QMI 方式相比 ECM 方式更稳定，推荐在 T527 平台使用
