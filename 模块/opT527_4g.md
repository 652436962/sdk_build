## 一、适配 USB 驱动

EC20 模组支持 QMI、ECM、RNDIS、USB 转串口 option 等驱动，本文选择 **QMI 驱动** 适配。

### 1. USB 驱动配置项

| USB 驱动 | 配置项                                                                          | 源文件                                      |
| ------ | ---------------------------------------------------------------------------- | ---------------------------------------- |
| ACM    | CONFIG\_USB\_ACM                                                             | \[KERNEL]/drivers/usb/class/cdc-acm.c    |
| QMI    | CONFIG\_USB\_SERIAL\_WWAN=yCONFIG\_USB\_SERIAL\_QMI\_WWAN=y                  | \[KERNEL]/drivers/usb/serial/qmi\_wwan.c |
| ECM    | CONFIG\_USB\_NET\_DRIVERS=yCONFIG\_USB\_USBNET=yCONFIG\_USB\_NET\_CDCETHER=y | \[KERNEL]/drivers/net/usb/cdc\_ether.c   |
| RNDIS  | CONFIG\_USB\_NET\_DRIVERSCONFIG\_USB\_USBNETCONFIG\_USB\_NET\_RNDIS\_HOST    | \[KERNEL]/drivers/net/usb/rndis\_host.c  |
| MBIM   | CONFIG\_USB\_NET\_DRIVERSCONFIG\_USB\_USBNETCONFIG\_USB\_NET\_CDC\_MBIM      | \[KERNEL]/drivers/net/usb/cdc\_mbim.c    |

### 2. 内核配置修改

在 `device/soc/allwinner/t527/patches/config/t527_standard_defconfig` 中添加：

```ini
CONFIG_USB_SERIAL_WWAN=y
CONFIG_USB_SERIAL_QMI_WWAN=y
CONFIG_GPIOLIB=y
```

禁用：

```ini
CONFIG_MEMORY_SECURITY=n
```

## 二、设备树配置

### 1. 添加 4G 模块电源控制节点

在设备树中添加 4G 模块的配置：

设备树文件路径：`device/board/forlinx/okt527/bootloader/configs/okt527/linux-5.10/board.dts`

在 `wifi_en` 节点后添加：

```dts
pwren_4g {
    compatible = "regulator-fixed";
    regulator-name = "pwren_4g";
    regulator-min-microvolt = <3300000>;
    regulator-max-microvolt = <3300000>;
    gpio = <&pio PB 13 GPIO_ACTIVE_HIGH>;
    regulator-always-on;
    enable-active-high;
    status = "okay";
};
```

unzip -o forlinx/quectel-cm.zip -d third_party/quectel/

    deps = [

## 四、自启动 quectel-CM 拨号工具

### 1. 修改 init 配置

修改 `device/board/forlinx/okt527/configure/rootfs/init.sun55iw3p1.cfg`：

```json
{
    "name" : "post-fs-data",
    "cmds" : [
        "restorecon",
        "restorecon /data/updater",
        "mkdir /etc/udhcpc 0777 root root",
        "wait /dev/ttyUSB2",
        "start quectel-cm"
    ]
}
```

### 2. 修改全局 init 配置

修改 `base/startup/init/services/etc/init.cfg`，在 `post-fs-data` 任务中添加：

```json
"mkdir /etc/udhcpc 0777 root root",
"wait /dev/ttyUSB2",
"start quectel-cm"
```

### 3. 内核源码修复（可选）

如遇到 `rtc_time64_to_tm` 函数未定义错误，需在 `drivers/staging/android/blackbox_common.c` 中添加：

```c
static void rtc_time64_to_tm(u64 time, struct rtc_time *tm)
{
    time64_to_tm(time, 0, tm);
}
```

### 3. secon 说明

- 格式：`u:r:domain:s0`
- 自定义 `quectel-cm` 域因无 SELinux 策略会启动失败，改用系统预定义的 `su` 域（`u:r:su:s0`）可正常启动。

## 六、遇到的问题及解决

### 问题一：缺少 busybox 工具

- **现象**：`busybox: inaccessible or not found`
- **解决**：

```bash
apt-get update && apt-get install -y busybox
```

### 问题二：QMI 设备节点未创建

- **现象**：`QMI device not found`
- **解决**：
  1. 确认 USB 驱动加载成功：`ls /dev/cdc-wdm0`
  2. 检查 USB 枚举顺序，确保 EC20 正常识别

### 问题三：编译时 blackbox_common.c 报错

- **现象**：`rtc_time64_to_tm` 函数未定义
- **解决**：在 `kernel/linux/drivers/staging/android/blackbox_common.c` 末尾添加：

```c
static void rtc_time64_to_tm(u64 time, struct rtc_time *tm)
{
    time64_to_tm(time, 0, tm);
}
```

### 问题四：打包脚本找不到 scripts 目录

- **现象**：`/home/openharmony/.../scripts: No such file or directory`
- **原因**：LICHEE_TOP_DIR 使用了 /home/openharmony 路径，但符号链接未正确解析
- **解决**：确保 `/home/openharmony` 符号链接存在且正确指向 SDK 目录

### 问题五：GPIO 控制相关错误

- **现象**：`GPIO control not available`
- **解决**：确保内核配置中 `CONFIG_GPIOLIB=y` 已启用

### 问题三：quectel-cm 与 /dev/ttyUSB2 时序问题

- **现象**：进程启动早于 USB 设备枚举，立即退出
- **解决**：启动前添加 `wait /dev/ttyUSB2`

### 问题四：DNS 解析问题

- **解决**：
  1. 修改 `build/config/components/musl/BUILD.gn`：
  ```ini
  OHOS_DNS_PROXY_BY_NETSYS=0
  OHOS_FWMARK_CLIENT_BY_NETSYS=0
  ```
  1. 修复 `third_party/musl/src/network/resolvconf.c`：
  ```c
  // 原：#ifdef OHOS_FWMARK_CLIENT_BY_NETSYS
  // 改：#if OHOS_FWMARK_CLIENT_BY_NETSYS
  ```

## 八、EC20 QMI 模式说明

quectel-CM 支持多种工作模式，使用 QMI 方式时：

- 设备节点：`/dev/cdc-wdm0`（QMI 控制通道）
- AT 命令口：`/dev/ttyUSB2`
- 网络接口：`wwan0`

### AT 命令切换模式

```bash
# 查询当前模式
AT+QCFG="usbnet"

# 切换到 QMI 模式
AT+QCFG="usbnet",1

# 切换到 ECM 模式
AT+QCFG="usbnet",0
```

**注意事项**：

1. EC20 模组需支持 QMI 固件版本
2. 不同地区运营商 APN 可能不同，需根据实际情况修改
3. QMI 方式相比 ECM 方式更稳定，推荐在 T527 平台使用
4. 4G 模块需要连接到正确的 USB 接口（通常是 USB1）
5. 编译前确保 ccache 已配置，可显著加速增量编译（从 1小时+ 降至 12分钟）
6. 打包时如遇 symlink 错误，需确保 `/home/openharmony` 正确链接到 SDK 目录
